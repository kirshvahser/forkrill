# StudyApp: сборка .ipa без Мака

## 1. Собрать в облаке (GitHub)
1. Зарегистрируйся на github.com и создай новый репозиторий (лучше Public: сборки на macOS там бесплатны, в Private лимит минут маленький).
2. Распакуй этот архив и перетащи в репозиторий ВСЁ содержимое, включая папку `.github` (кнопка Add file → Upload files).
3. Открой вкладку **Actions** → **Build IPA** → **Run workflow**. Сборка идёт 5-10 минут.
4. Когда станет зелёной, открой её и внизу скачай артефакт **StudyApp-ipa** (это zip, внутри `StudyApp.ipa`).
5. Если сборка красная, открой лог, скопируй текст ошибки и отправь мне.

## 2. Поставить на айфон
1. Передай `StudyApp.ipa` на телефон (iCloud Drive, Telegram, AirDrop с другого устройства).
2. Установи AltStore или SideStore (с их официальных сайтов, инструкции там) и открой .ipa через «+» в приложении.
3. Раз в неделю нажимай Refresh в AltStore/SideStore (или настрой автообновление).

Bundle ID по умолчанию `com.example.studyapp`. Если установка ругается, что он занят, поменяй его в `project.yml`.
